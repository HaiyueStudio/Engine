# 雾港素材来源 / The Last Lantern asset credits

- 中英文台本、角色与雨夜场景为本示例原创。HYA 图形及动画可用 `tools/create-art.mjs` 重建。
- 环境音乐为 `tools/create-audio.mjs` 生成的原创循环音轨。中英对白 WAV 使用 eSpeak NG 的 Spellophone 0.2.1 封装合成原台词。交付素材包含生成的 WAV。合成器作为独立制作工具获取。
- 示例代码、台本与生成素材采用交付目录的 MIT 许可证。

工具来源：[eSpeak NG](https://github.com/espeak-ng/espeak-ng) · [Spellophone](https://spellophone.spellingcreator.org/guide/node)
