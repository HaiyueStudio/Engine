# ADR 0118：G09 冷启动与稳态的独立校准

- 状态：接受采样设计；具体共同预热长度须由完整校准产生，不能预先声称通过。
- 日期：2026-10-07。
- 授权：用户要求完成独立无人值守采样、确定共同冷启动／稳态口径并重建同机基线，保留 5% 回归预算。
- 配置：[framegraph-sampling-021.json](../../../config/framegraph-sampling-021.json)。

## 原因与范围

[既有诊断](../../../review/engine-0.2.1/g09/performance-host-diagnosis.md)取得完整 Forward 人口，但旧 A0 的八灯 CPU 轮次不稳定。短窗口对预热长度敏感，追加诊断又包含主机噪声。不能仅延长预热、挑选尾段或放宽预算修复门禁。

新增版本化的 G09 开发基线采样协议，复用原单灯／八灯、静态高重叠等确切配方、质量和 A0/B4 构建。它是包含既有后处理的 inherited Forward 对照，不冒充效果关闭的 F0 或完整 F0–F8。G01/G05 及旧 `framegraph-021-default-path-preflight-v1` 不改，既有失败原样保留。硬件范围继续按 [ADR 0117](0117-native-021-hardware-scope.md)。

## 口径

冷启动：每项使用新浏览器配置、新 device。分别记录场景初始化、显式 pipeline 预编译以及其后前 120 帧 CPU；不清空 OS／驱动缓存，不把它称为 GPU 冷缓存测试。冷启动原始帧及阶段值完整保留；没有既有冷启动预算的指标只报告实际数值、轮次稳定性和比值，不编造新上限。

校准：每 case／variant 三轮 AB/BA/AB，每次连续记录 12000 帧 CPU、阶段、frameWall、queueWait。预登记候选边界为 1200、3600、6000 帧；每个候选之后比较两个相邻且各含 3000 帧的窗口。所有 case 与两个 variant 均须满足：每个窗口的三轮 P95 通过既有 spread≤20%、CV≤10%，两个窗口的等权合并 P50 和 P95 变化绝对值均≤5%。取最早共同通过的边界；选择器不比较 A0/B4 加速比。若没有共同边界，校准失败，基线阶段不得启动。不同候选只是校准分析窗口，所有原始数据仍保留。

稳态：将上述校准的哈希、共同边界、源码／配置指纹写入冻结协议，再启动独立的新三轮 A0/B4 人口。每次保留全部预热帧及其后 3000 帧 CPU；GPU 单独预热 120 帧，采样 300 帧，保留 pass 合计与整帧 render/compute span。CPU 样本扩大用于减少短窗口尾部统计波动，两版本完全一致，不能将旧人口剪裁或拼接为新人口。

正式比较沿用 CPU、GPU P95 **5% 回归上限**和三轮 spread≤20%、CV≤10%；frameWall 保留分布与稳定性。启动阶段与稳态分列，不能相互混合或把各子阶段分位数相加当整帧。CPU update/record/submit 是已有粗粒度观测，不能称为完整 G09 declare/compile/resolve 等非重叠归因。

## 执行与证据

入口：[无人值守包装器](../../../scripts/run-framegraph-unattended.ps1)、[采样 CLI](../../../scripts/verify-framegraph-sampling.mjs)、[纯策略与验证器](../../../scripts/webgpu-gate/framegraph-sampling-policy.mjs)。每项实测冷却至少 120 秒；CPU≤15%、GPU≤10%，硬件／驱动、浏览器、功耗方案、thermal flags 均校验。为避免长时间占用约 10% CPU 的交互界面在一次前测后立即打断采样，额外要求入场前连续三次 CPU≤5% 的就绪观测，相邻观测之间等待三秒；原 15% 拒绝阈值不放宽。主机忙时只允许在任何计时帧产生前等待，最多十分钟并保存全部就绪观测；采样后失败则保留整项并终止，不重采该项来拼接人口。

计时前先完成两场景整幅像素、分配及零残留检查。采样进程只写文件，独立于交互进度显示；逐进程监控保持运行。仅依用户既有授权临时停止并阻止 Search 自启，在 `finally` 恢复原运行与启动状态；不调整安全软件或电源方案。

原始捕获、生产者快照、哈希、源码／构建／配置指纹、就绪观测、进程记录、校准与冻结协议、A0 基线以及 B4 比较全部归档。开发主机、dirty 源码的结果不能授予 G05/G07 或 clean release 资格。改变测量代码会改变测量源码指纹，历史正确性证据保持历史身份，新计时使用当前测量入口的像素预检。
