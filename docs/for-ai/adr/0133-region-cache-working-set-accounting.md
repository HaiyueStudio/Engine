# ADR 0133：区域像素缓存与整帧工作集分别计量

- 状态：Accepted
- 日期：2026-10-20
- 决策来源：用户明确选择“缓存与工作集分开计量”。
- 取代范围：仅澄清 [ADR 0132](0132-gui-layout-interaction-022.md) 及 G01 区域缓存上限的统计对象；原合同、已完成 G01 报告和失败记录保留。

## 问题

整帧 RGBA16F／4×MSAA 的颜色及 resolve 在 1080p 占 82,944,000 bytes（79.10 MiB）。把它算作保留像素缓存，会在缓存为零时拒绝正常的完整绘制；普通全帧参考也需要相同工作颜色。

## 决策与方法

像素缓存继续受同设备共享的 8 区域／64 MiB 上限约束，包括缓存 MSAA、resolve、可见裁剪副本及安全退役重叠。超限明确回退，不能隐去内容。

普通整帧合成工作集单独计量，包括工作颜色、MSAA、resolve 及退役重叠。可复用分配容量，但每次记录必须完整初始化，不能依赖上帧像素。尺寸变化采用新分配事务；旧资源在未提交记录及最后队列使用结束前继续保留和计数。

区域统计同时报告缓存颜色、工作颜色、其中退役工作颜色、所有区域深度，以及区域颜色加深度合计。此合计只是完整 GPU 资源的子集；原生证据另外保留完整 GPUResourceTracker 快照，G13 按原有总 GPU 资源要求验收。字节为分配估算，不能称为驱动实测驻留。

## 结论与边界

本决定不提高缓存限额，不更改格式、精度、画质容差、场景或其他预算。机器合同见 [工作集补充合同](../../../config/region-working-set-022-contract.json)；实现与当前证据见 [G04 评审](../../../review/engine-0.2.2/README.md)。隔离试验保留为历史，生产验证不能继续使用测试适配器。完整 3D、多视图、设备恢复及正式性能资格仍按 G04／G13 原范围完成。
