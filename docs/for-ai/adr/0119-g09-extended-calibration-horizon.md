# ADR 0119：G09 扩展校准观察范围

- 状态：接受观察范围修订；不代表稳态或性能验收通过。
- 日期：2026-10-07。
- 替代范围：[ADR 0118](0118-g09-cold-steady-sampling.md)中的校准总帧数与候选集合，其余合同继续沿用。
- 配置：[v2](../../../config/framegraph-sampling-021-v2.json)，历史 [v1](../../../config/framegraph-sampling-021-v1.json)。

## 依据

[完整 v1 校准](../../../review/engine-0.2.1/g09/unattended-sampling.md)在用户最小化 Codex 后完成两个场景、两个版本的全部三轮。主机前后检查全部通过，但预登记的三个候选边界均无共同平台。最晚边界的单灯 B4、八灯 A0 P95 仍分别下降约 16.55%、11.54%。原始阶段数据表明变化主要在 CPU record，不能据此认定具体 JIT、GC 或驱动根因，也不能截取最后窗口作为已验收基线。

原 v1 人口和独立重算的失败结果保留。修订旨在观测先前没有覆盖的后续区间，不调整引擎实现、 workload、统计量、预算或已有边界，也不因 A0/B4 加速比选择边界。

## 决策

v2 每项连续保留 **24000 帧**。在原候选 1200、3600、6000 基础上，预登记增加 12000、18000；每个候选仍比较两个连续 3000 帧窗口。选择最早同时满足所有版本与场景的边界：每窗口三轮 P95 spread≤20%、CV≤10%，跨窗口合并 P50/P95 绝对变化≤5%。没有共同边界即失败，不自动扩展或重复尝试。

本次修订在新数据产生之前固定。用完整的新校准人口重新观测所有候选，不能沿用、拼接或重新标记 v1 样本。通过后冻结，再使用全新的三轮基线人口。稳态仍是全部 3000 CPU 样本与 300 GPU 样本，冷启动口径、120 秒冷却、主机阈值、GPU 独立预热、原 **5% CPU/GPU P95 回归预算**均不变。

捕获必须声明 v1/v2 身份并匹配各自的完整帧数；未知协议、错标协议或短人口均拒绝。当前入口产生 v2，v1 配置保留供历史解释。历史证据不能通过新源码指纹验证而冒充当前证据，已完成的历史重算及其哈希一并保存。

该流程仍为 inherited Forward 开发基线；不得宣称完整 F0–F8 或 G05/G07 clean release 通过。
