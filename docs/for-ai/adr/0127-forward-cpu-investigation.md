# ADR 0127：Forward CPU 相对回归作为调查项

- 状态：接受；2026-10-15 用户明确批准“CPU 5% 改为调查项，其余门禁保持”。
- 范围：仅取代 [ADR 0126](0126-g05-stability-and-evidence-reuse.md) 中 G05 Forward CPU P95 相对 5% 的硬门禁。GPU 5%、房间／实例预算、生产帧节奏、画质、生命周期与资源要求保持。

## 问题

同一干净候选的独立 Forward 报告有两项 Edge CPU 超线；固定 48 次 AB/BA 与 AA/BB 对照中，16 对同版本测量有 12 对绝对相对差超过 5%，最大为旧版本 0.920→1.295 ms（+40.8%）。完整生产矩阵 36 次捕获、64,806 个稳态间隔全部通过，最差 P99 16.92 ms，启动交互与稳态均无超过 50 ms 的间隔。

同版本对照证明存在测量变化，不能证明新版全部差距都是噪声；CPU 频率、驱动或 JIT 的具体归因仍未完成。相对微基准超线与生产卡顿须分别判断。

## 结论

Forward CPU 5% 保留为调查触发线，完整记录原值、原失败和调查结果，不再单独阻止本机生产性能资格。原始 Forward 报告仍为失败，不能改写为通过；验收报告单列新的解释。其他硬门禁不变，生产帧节奏、资源增长、画质或 GPU 退化仍会阻断。

## 解决方法

1. 只调整专项验收层，不改冻结预算、采样器、样本、预热、顺序或运行时。`cpuP95Ratio > 1.05` 进入 `cpuRegressionInvestigations`；`gpuP95Ratio` 的原 1.05 上限仍必须满足。
2. 检查 CPU/GPU 各四项覆盖、原判定一致性及有限数值；缺项、伪造通过、未知指标或改变阈值仍失败。跨轮稳定性继续按 ADR 0126 单列，不能将其他预算失败转成调查项。
3. 七份完整证据、全部原始捕获、当前输入和重建可执行字节仍须独立核对；原采样提交与验收提交分列。仅文档与具名验收文件变更允许复用，运行时或采样器变化仍需新采样。
4. AA/BB 对照仅支持调查结论，不替换正式样本，不从回归数值中扣除“噪声额度”，不自动重试到通过。该调整不完成独立包、Shader、生命周期和最终发布链，也不授权发布或基线晋升。

当前证据与剩余工作维护在[验收结论](../../../review/engine-0.2.1/README.md)。
