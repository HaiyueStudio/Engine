# ADR 0104：Rive 研发分支与 0.1.1 发布范围

状态：接受；按用户要求隔离未完善的 Rive 能力，候选整理不修改版本号、不授权发布。

## 决策

`feature/rive-development` 保留分支切分时的完整 Rive 实现。`release/0.1.1`
移除专用 `.riv` 导入器、转换适配器、官方运行时依赖、素材、差分工具、
预览服务转换接口和三个 Rive 示例。后续 Rive 工作只在研发分支继续；
重新纳入发布前必须完成能力和证据审查。

本决策取代 ADR 0087–0092 中 Rive 实现进入当前开发/发布分支的安排，
保留原 ADR 的研究和设计历史。来源无关的 HYA 文档、状态机、文本、
向量图形、脚本沙箱及 Lottie/Live2D 转换能力继续保留。

文本使用标准预乘透明度采样；删除 Rive oracle 专用的 Canvas 像素量化和
四个子像素位置采样。这样普通 HYA 文本不再承担对齐第三方渲染器的开销。

## 验证边界

`npm run release:no-rive` 检查源码、资产、依赖、锁文件和示例清单；
`npm run release:no-rive -- --artifacts` 额外检查已构建包和示例。
后者接入现有 `release:scope:check`。必须先构建，避免旧的忽略产物混入候选。

`docs/for-ai/rive-hya` 保留为历史契约资料，供通用 HYA census 对照测试与
禁止第三方运行时进入浏览器闭包的安全检查使用。这不构成 Rive 支持声明。

候选范围、验证结果及未解决发布问题记录在
[0.1.1 候选检查报告](../../../review/release-0.1.1.md)。
