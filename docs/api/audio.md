# Game audio (0.2.3 development candidate)

`@haiyue/engine/audio` exposes the original `OwnerSafeAudioMixer`, its four existing request/options/stats/bus types and two new volume/capability types. The experimental entry retains its original five names and the same class. `@haiyue/extensions/audio` exports `createGameAudio` and four configuration/controller types; importing it creates no context, decoder, nodes, timer or GUI.

Pass an existing mixer to `createGameAudio({mixer})`. The facade borrows it. Its private voice lease is maintained by that original owner: endings and eviction remove IDs immediately; external replacements cannot be changed by an old emitter. `dispose()` stops only this facade's live voice IDs, releases position callbacks and cancels fades. Installed buffers, the mixer, applied global volume settings and borrowed AudioContext remain application-owned. Dispose the mixer and close an application-created context separately.

Volume values range from 0 to 4. Mute retains configured values while applying zero master gain. `exportProfile()` returns immutable `haiyue-game-audio` version 1 data; restore validates it completely before committing. Persist through the existing GameSaveService, as in the [audio example](../../examples/game-audio/index.html). `fadeBus()` linearly changes music/sfx/ui from its current configured volume over caller-supplied milliseconds. Call `update(deltaMs)` once from the application loop; zero-duration fades commit immediately. Setting a bus explicitly cancels its pending fade. No extra audio clock is introduced.

Bind at most 128 unique owner/channel emitters. Positions and listener callbacks return finite render-unit pairs. `maxDistance` and `attenuation` are positive finite values; attenuation defaults to 1. `panStrength` is nonnegative, default 1. Gain is `base * max(0, 1 - distance/maxDistance)^attenuation`; pan is horizontal distance/maxDistance times strength, clamped to -1…1. Base is the original request volume unless emitter volume explicitly replaces it. Spatial gain is installed before source start, avoiding an unattenuated transient. Unbinding restores the current owned voice's dry gain and pan. Position callbacks read the application model; invalid samples reject before that update advances fades or applies spatial changes.

`getCapabilities().stereoPan` is null before the mixer establishes a context, then reports StereoPanner availability. A null/false result rejects emitter binding with [E_AUDIO_CAPABILITY_UNAVAILABLE](errors/E_AUDIO_CAPABILITY_UNAVAILABLE.md). Resume/unlock in a real user gesture before probing an uninitialized mixer. Explicit suspend/resume operates on the shared context and affects its other borrowers; disposal never implicitly suspends or closes it. Defaults remain 128 voices total / 32 per owner, maximum 1,024; decoded buffers accept one or two channels. A newer install/remove/decode intent prevents older asynchronous decode completion from resurrecting replaced or disposed data.

HYA retains its original sample-frame scheduling, codec/integrity validation, decoded handles and bus gain chain. It may borrow the same explicit context through `createBrowserHyaAudioHost`, without routing through tick-based game play requests or multiplying HYA bus gains twice. Voices and resources retain their original owners. The Native PCM bank is not a Web Audio adapter. Mac/iPhone capability, unlock and background recovery remain G11 device qualifications. Pair local Engine/extensions candidates; published 0.2.2 packages do not include these stable entries.
