# E_PHYSICS_QUERY_LIMIT

The shape query exceeded its candidate limit after category/mask, sensor and exclusion filtering. The default and absolute maximum are 256; callers may select a smaller positive limit. The query throws instead of returning a truncated nearest-hit result.

Use appropriate collision filtering or reduce scene density in the query region. Character preparation leaves its prior position unchanged when this error is raised before committing the move. World bodies and borrowed resources remain owned by their original world. See [character2d](../../../extensions/README.md#character-2d-023-candidate).
