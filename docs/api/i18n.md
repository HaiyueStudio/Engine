# 国际化 API

入口：`@haiyue/extensions/i18n`。可选稳定接口，根入口不聚合。

- `I18n({ locale, fallbackLocale, fallbacks?, onDiagnostic? })`：独立语言上下文。
- `register(pack)`：校验并复制同步语言包；替换活跃语言包会刷新绑定。
- `registerLoader(locale, loader)`：注册异步 JSON loader，重复注册报错；loader 接收 locale、AbortSignal。
- `preload(locale, signal?)`：缓存语言包及回退链，不改变当前语言。不预加载图片。
- `setLocale(locale, signal?)`：加载成功后提交语言；被新切换/取消/销毁取代返回 false，加载或验证失败 reject。
  未注册的地区可使用显式回退/默认语言。没有任何可用包则 reject。订阅者异常会聚合抛出，语言提交不会回滚。
- `text(key, params?)`：纯文本插值；复数以数值 `count` 按实际命中的语言包选择类别。
- `asset(key)`：返回语言包中资源路径，缺失为 undefined；路径相对谁由加载器决定。
- `formatNumber/formatDate(value, options?)`：使用当前语言的 Intl 格式化。
- `subscribe(listener)`：收到 `{type: 'change' | 'dispose', locale}`，返回取消函数。
- `dispose()`：取消加载，通知并移除绑定，释放语言包；幂等。
- `validateLocalePack(unknown)`：返回规范化语言标识、复制并冻结的数据，格式错误抛 TypeError。
- `checkLocalePacks(reference, translations)`：返回缺失/多余 key、文字类型和占位符不匹配的问题列表。格式错误仍抛出，不读取图片文件。
- `collectLocaleCharacters(packs, extra?)`：收集所有文字/复数分支字符，加上 ASCII 与额外动态字符，供 GUI 字库配置；按 Unicode 码点去重。
- `bindI18nText(i18n, GuiLabel | GuiButton, key, {params?, signal?})`：立即绑定，返回 refresh/setParams/dispose。
- `bindI18nImage(i18n, GuiImage, key, {load, textKey, fallbackLabel?, signal?})`：返回 ready/error/description/refresh/dispose。
  ready 对应最近一次请求，加载失败通过 error 读取；旧图保留，无旧图时显示 fallbackLabel。
- `createI18nTextureLoader(assetManager, baseUrl)`：复用 AssetManager 的纹理缓存和引用计数。

文本缺失返回 key，参数缺失保留 `{name}`；开发诊断显式通过 onDiagnostic 开启，相同语言/错误/key 只报告一次。
所有文本都是普通文字，不解析 HTML。占位符名称支持字母、数字、下划线和点，不支持嵌套 ICU 表达式。

图片 loader 返回 `{texture: GPUTexture, release()}` 租约；包括过期请求在内的所有已返回租约均由绑定释放。
release 不得抛错。不得传入未经租约管理的共享纹理并在 release 中直接销毁其他消费者的资源。
绑定保留 width/height/UV，游戏应使用统一的艺术字画布比例。dispose 恢复原有图片源和 fallbackLabel 状态。
每个目标由一个绑定拥有；删除节点时必须取消绑定，不能仅从 GUI 树中移除。
