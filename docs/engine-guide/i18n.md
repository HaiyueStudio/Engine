# 游戏文字与艺术字的国际化

[运行示例](../../examples/i18n/index.html) · [示例源码与验收](../../examples/i18n/README.md) · [API](../api/i18n.md)

## 准备语言包

每个语言包是 JSON，不包含函数或 TypeScript 类型。key 表示语义，不以中文原文充当 key。
艺术字以相同逻辑宽高/画布比例导出，翻译图片可有不同物理分辨率。

```json
{
  "schemaVersion": 1,
  "locale": "en",
  "messages": {
    "menu.start": "Play",
    "score.current": "Score: {score}",
    "coins": { "one": "{count} coin", "other": "{count} coins" }
  },
  "assets": { "menu.start": "assets/start.en.png" }
}
```

复数始终包含 other，不要求所有语言拥有相同复数类别。参数替换不自动格式化数字；需要千分位时，
把 `i18n.formatNumber(score)` 作为 score 参数传入。count 本身仍传数值。
assets 也可存储字体等资源路径，但首版只有 GuiImage 的自动资源绑定；字体/RTL 排版由宿主配置。

## 准备 GUI 字库

GUI 默认字库只含有限字符。创建场景前使用 `collectLocaleCharacters(packs, extra)` 收集已知语言包文字，
作为 `gui: { font: { chars, atlasSize: 1024 } }` 的 chars。extra 应包含语言选择按钮和运行时插入的额外字符。
系统字体必须能绘制这些字符；字体图集大小按字符数量配置。海量翻译不应全部放入单一图集，应按场景分包。
动态用户输入、字体自动扩容与复杂文字 shaping 不在本模块中。示例预加载三种语言以建立完整字符集。

## 创建运行时与绑定

```ts
import { I18n, bindI18nText, bindI18nImage, createI18nTextureLoader } from '@haiyue/extensions/i18n';
import { GuiLabel, GuiImage } from '@haiyue/engine/gui';

const i18n = new I18n({
  locale: 'zh-CN', fallbackLocale: 'en',
  fallbacks: { 'zh-HK': ['zh-Hant'] },
  onDiagnostic: diagnostic => console.warn(diagnostic),
});
for (const locale of ['en', 'zh-CN', 'zh-Hant']) {
  i18n.registerLoader(locale, async (_, signal) => {
    const response = await fetch(`./locales/${locale}.json`, { signal });
    if (!response.ok) throw new Error(`Language pack HTTP ${response.status}`);
    return response.json();
  });
}
await i18n.setLocale('zh-CN');

const lifetime = new AbortController();
const score = new GuiLabel();
const scoreBinding = bindI18nText(i18n, score, 'score.current', {
  params: { score: 1200 }, signal: lifetime.signal,
});
scoreBinding.setParams({ score: 1800 });

// engine 已初始化；将这些节点加入场景 GuiRoot。
const title = new GuiImage({ width: 240, height: 80 });
const fallback = new GuiLabel();
const artwork = bindI18nImage(i18n, title, 'menu.start', {
  textKey: 'menu.start', fallbackLabel: fallback, signal: lifetime.signal,
  load: createI18nTextureLoader(engine.assetManager!, new URL('./', location.href).href),
});
await artwork.ready;
if (artwork.error) console.warn(artwork.error);

await i18n.setLocale('en');
await artwork.ready; // setLocale 只等待语言包；图片另行等待。
// 宿主可把 artwork.description 提供给原生/DOM 无障碍层。

// 场景退出：先释放绑定，然后移除 GUI / 销毁引擎。
lifetime.abort();
// 如果运行时由多个场景共享，不要在单个场景退出时销毁它。
i18n.dispose();
```

原生环境使用同一套 JSON，通过 register 提供已加载的数据或注入平台 loader，无需 fetch/DOM。
没有隐式语言检测或持久化；由游戏读取用户偏好后调用 setLocale，成功后保存。
运行环境需有 Intl.getCanonicalLocales、Intl.PluralRules、Intl.NumberFormat、Intl.DateTimeFormat 和 AbortController。

## 开发检查与切换策略

使用 `checkLocalePacks` 对照基础语言检查 key 和参数。不完整的翻译仍可在运行时通过回退显示；
CI 是否允许缺失由游戏决定。资源文件存在性和原生打包路径需要游戏自身的构建检查。

快速连续切换只允许最新的语言请求提交；图片也有独立的取消与过期检查。
图片加载时保留旧图，失败读取 artwork.error，可调用 refresh 重试。这不是全屏原子换肤。
每个节点只绑定一次；detach 不意味着永久销毁，移除后必须主动 dispose 或 abort。
