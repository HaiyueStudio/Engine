# 海月 示例目录

本文档整理项目中所有示例的功能说明。

---

## 示例列表

| 示例 | 目录 | 功能说明 |
|------|------|---------|
| **Transform3D 基向量** | `examples/transform3d-basis/` | 自定义 3D 基向量与局部坐标映射演示 |
| **MSAA** | `examples/msaa/` | 演示 4x MSAA 抗锯齿效果 |
| **混合场景** | `examples/mixed-scene/` | 多种几何体和材质的混合渲染 |
| **Reverse-Z** | `examples/reverse-z/` | Reverse-Z 深度策略演示 |
| **深度材质** | `examples/depth-material/` | 深度渲染（线性深度可视化） |
| **2D 图形** | `examples/shapes2d/` | 2D 几何体（矩形、圆、三角形、多边形） |
| **网格辅助** | `examples/mesh-helper/` | AABB/OBB/线框辅助可视化 |
| **视口裁剪** | `examples/viewport-scissor/` | Viewport 和 Scissor 矩形裁剪 |
| **渲染到纹理** | `examples/rtt/` | RTT 离屏渲染 + 纹理采样 |
| **实例化渲染** | `examples/instancing/` | 实例化网格渲染（大量相同物体） |
| **轨道控制** | `examples/orbit-control/` | 轨道相机控制器（旋转/缩放/平移） |
| **相机切换** | `examples/camera-switch/` | 多相机切换 |
| **位图文字** | `examples/bitmap-font/` | 位图字体渲染（normal/SDF/MSDF） |
| **Blinn-Phong** | `examples/blinn-phong/` | Blinn-Phong 光照材质 |
| **交互** | `examples/interactive/` | 射线拾取交互（点击/悬停） |
| **立方体纹理** | `examples/cube-texture/` | 纹理映射到立方体 |
| **后处理** | `examples/postprocess/` | 后处理效果（FXAA/高斯模糊/灰度） |
| **线条** | `examples/lines/` | 3D 线条渲染 |
| **混合模式** | `examples/blending/` | 颜色混合模式（normal/additive） |
| **视锥体裁剪** | `examples/frustum-cull/` | 视锥体裁剪演示 |
