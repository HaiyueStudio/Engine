# Live2D comparison samples

The bundled runnable fixture lives in [`examples/live2d-hya-compare/samples`](../../../examples/live2d-hya-compare/samples/) and is an original HaiYue MIT capture fixture.

The example also supports local directories containing a licensed `model3.json`, `.moc3`, textures, and Motion3. Official Live2D sample models are linked in the example manifest but are not copied here because their Free Material License requires explicit acceptance. Cubism Core is loaded only from the caller-configured URL.
