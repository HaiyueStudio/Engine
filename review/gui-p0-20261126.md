# GUI P0：问题、方法与结果

状态：P0 实现与自动化验收完成，2026-11-26。范围见 [ADR 0141](../docs/for-ai/adr/0141-gui-visual-foundation.md)，对应 [原方案 P0](gui-component-visual-plan-20261126.md)。不发布版本，不修改既有发布证据。

## 使用

```ts
import {GuiRoot, GuiButton, GuiInput, GuiThemeResource} from '@haiyue/engine/gui';

const root = new GuiRoot({theme: GuiThemeResource.createTheme('light', 'comfortable')});
const button = root.add(new GuiButton({
  text: '继续', variant: 'primary',
  style: {radius: 10, parts: {label: {color: '#fff7ed'}}}
}));
button.loading = true; // 自动借用 GUI 时钟；置 false 结束

const input = root.add(new GuiInput({
  prefix: '@', suffix: 'px', clearable: true,
  invalid: true, helpText: '请输入有效名称',
  style: {parts: {help: {color: '#d43852'}}}
}));
input.setVisualState({invalid: false});
```

`width`／`height` 仍是开发者显式尺寸；省略高度时才跟随 root 的密度。帮助文字绘制在输入框下方，调用方布局需预留 22 个逻辑像素。`padding` 保持原均匀语义，`paddingY` 可单独配置垂直留白。Button 通过 paddingY 避免压缩文字高度。

实例 `style` 及其状态字段在主题层之后合并；命名部件使用 `parts`，如 Button 的 label、Checkbox/Radio 的 indicator/label、Switch 的 track/thumb、Modal 的 title/body/close/confirm/cancel、Input 的 help。已有 `setStyle`、主题资源热更新、NineSlice、图像皮肤和自定义 painter 保留。根实例颜色与部件颜色是不同的字段路径，指定部件颜色时以该部件配置为准。

组合控件可调用 `owner.bindPart('body', borrowedChild)`，撤销返回的句柄不会删除 child。`getPartStyle(name, state)` 可供原有自定义 painter 查询部件样式。自定义动画用 `setActivity(deltaMs => { /* 更新已有元素 */ })`，返回 false 或释放句柄停止；不要创建每组件 RAF。

原始阴影／渐变／分角圆角等是逻辑像素样式；阴影 blur 0–128，角半径受盒尺寸限制，图标旋转单位为度。图像、字体和 GPU 句柄继续借用，不进入 JSON。可序列化的普通嵌套 style/state/part 数据和新增控件属性可往返，资源绑定仍由应用恢复。

## 实现归属

一个主题解析器、一套字体 owner、一份几何／裁剪 shader helper、原三个 GPU pass、一套输入域和一个活动时钟。控件默认 skin 与自身 painter 同文件，按需 GUI 入口不会为默认 skin 导入全部控件。外部 UI 仓库只作为设计参考，没有运行时依赖。

普通单字体控件仍使用已有局部 paint／glyph／vertex 更新；多字体使用已有顺序计划，未知 painter／live getter 保留保守回退。新增光晕、阴影和旋转的外扩计入旧／新 damage bounds，隐藏动画不持续重绘。

## 性能适用范围

普通单字体场景保留两次绘制，普通描边盒的形状顶点数减半；九组原生画廊的静态观察期没有新增 GUI 缓冲上传，GPU validation 错误为 0。隐藏、离屏、禁用和 reduced-motion 的活动暂停由回归测试覆盖。

同源前后 CPU 诊断使用共享 audit GPU，各档七个样本；它不包含真实 GPU 执行和队列时间，不能作为正式性能基线。4,096 控件全量变化时，mutation 中位数由 9.81→11.62 ms、record 由 34.42→40.11 ms；仍需可视窗口虚拟化，不宣称所有动态负载提速。局部更新、原样本和原预算保留，没有提升既有发布资格。本批未进行新的 Mac／iPhone 物理设备验收。
