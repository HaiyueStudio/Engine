# G09 Intel GPU 重置追查

日期：2026-10-03（Asia/Shanghai）。本轮没有找到可采用的运行时修复；G09 仍未取得正确性、稳定性或性能资格。

## 新证据

本机 macOS 内核在失败测试期间记录了 `timeout waiting for IntelAccelerator`、`GPURestartSignaled` 和 `GPURestartEnqueued`。系统 `.gpuRestart` 报告明确标记 `GPU Reset`，应用为 Google Chrome Helper 154.0.8037.93，设备为 Intel UHD Graphics 630，系统为 macOS 26.6.2（25G83），并含 `Intel GPU Hang Summary`。

这证明该时段发生了系统级 GPU 挂起/重置。它不证明硬件已经损坏，也没有区分 Metal 驱动、Dawn/Chromium、系统状态及触发工作负载之间的具体责任。不能继续只用 FrameGraph 资源复用或某一段 AO 算法解释全部异常。

一个有明确时间窗口的样本：带窗口 Chrome 的首轮从 **06:52:37.201 到 06:53:35.909**；该窗口内 **06:52:47.664、06:53:13.872** 均发生 Intel 等待超时和重置信号。该轮固定数据/读回校验失败，WebGPU 诊断却没有报告 `device.lost` 或 validation error。因此引擎已有的 device-loss 自动恢复不能覆盖本轮所有静默错误，也不能通过“没有 WebGPU 报错”认定样本健康。

内核可能对一次故障的多个上下文多次发信号，日志行数不等于独立重置次数。报告摘录保留原始路径和文件哈希；完整内核筛选日志、原始浏览器输出与源码指纹见 [证据索引](intel-gpu-reset-checks.json)。

## 本轮候选对照

全部使用真实 Intel Gen9、相同 B4 构建、64×64 完整渲染链、固定场景与五帧人口，保持独立已知答案校验和同提交双读回。没有扩大像素容差、挑选成功路径或把失败重试提升为通过。

| 对照 | 结果 | 结论 |
| --- | --- | --- |
| 默认参数 / 去掉 `--enable-unsafe-webgpu`，交错 8 会话 | 默认 0/4 通过；去掉参数 2/4 通过，另 2 次图像异常 | 参数变化不能消除异常，未修改共享 runner |
| 保留 pass 和绑定描述，只简化 AO 片元计算，8 会话 | 原始 2/3 通过；全部简化 1/2 通过；单独简化原始 AO、降噪、升采样各 0/1 通过 | 未找到有效的单段绕过；简化改变了画面，只用于定位，不能替代产品像素验收 |
| 无头 / 带窗口初版，4 会话 | 无头 2 次失败；带窗口 2 次未找到初始页面 | 后者是启动夹具失败，不能归类为渲染失败 |
| 带窗口并跳过首次启动页面，2 会话 | 1 次读回校验失败、1 次通过；失败窗口有上述内核重置 | 单纯切换带窗口模式不足以解决问题 |

共 22 个浏览器会话，其中 20 个取得原生渲染数据（6 个通过、14 个失败），2 个启动夹具失败。小样本、同机连续运行且存在系统级故障，不把不同组成功比例当作稳定性或性能比较。去掉 `unsafe`、简化 shader、使用带窗口模式均没有达到采用条件。

## 下一步恢复和定位顺序

1. 先确认屏幕点亮且已解锁，在保存其他工作后重启 macOS，再用未改 shader 的完整链做有限对照，同时检查同时间窗口的 GPU 重置日志。此前每次使用全新测试 Chrome 进程/配置仍会失败；单独重启测试浏览器已经不足以排除系统状态。重启是否有效尚未验证，不承诺它能根治。
2. 若冷启动后仍出现重置，在另一台真实 Intel 设备或另一套系统环境运行同一份带哈希夹具，以区分设备/系统特有条件与可移植的触发序列，再继续缩减至无 Engine 的最小复现。已测试浏览器版本和简单无 Engine 探针的边界见前两轮追查报告。
3. AMD 独显可继续用于开发验证，但不能用它的通过结果替代 Intel 兼容性验收。生产设备丢失恢复保留现有实现；不通过无限重试、降低整体验收要求或默认删除 AO 来掩盖本轮静默错误。

本轮未执行系统重启或更改系统电源/显示设置。屏幕状态问询尚未收到确认，因此没有将锁屏、合盖或休眠当作已证实原因。

## 变更与检查范围

本轮只重建私有诊断夹具，新增独立开发实验、系统故障证据和本报告。Engine、生成 shader、生产配置、共享门禁、预算均未改动。首次开发脚本导入路径错误在启动浏览器前修正，不计入 22 个会话。文档/API 检查结果记录于证据索引。
