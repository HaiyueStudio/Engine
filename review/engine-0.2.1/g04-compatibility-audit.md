# G04 compatibility audit

**2026-09-28. G04 complete; G05 ready and not activated.** This report supersedes the earlier transparent and legacy-AO checkpoints; it does not authorize publication.

## Implemented scope

- Standard and extended opaque PBR use complete light lists. An explicit G-buffer proxy mask preserves the winning surface and the prepared object-table slot for clearcoat, IOR/specular and sheen.
- Sorted transparent and transmissive PBR retain the complete source list, original shadow indices, opaque linear HDR snapshot, and layered material behavior.
- The user selected the frozen AO contract. Deferred evaluates GTAO/SAO/SSAO after surface preparation and before lighting. Screen-space visibility modulates ambient/environment terms; direct illumination, emission and transmitted scene radiance remain unmodulated. Default Forward retains its existing postprocess behavior. AO debug display remains a postprocess option.
- AO has a private storage-buffer ABI, avoiding a seventeenth sampled texture in layered PBR. A 256-byte header/padding precedes row-aligned RGBA16F visibility. The pass binding is 17 for Reference/Tiled and 15 for full Forward. Layered PBR requires five fragment-stage storage bindings, below the core limit of eight; undersized devices and visibility buffers fail explicitly. No stable API or material uniform ABI changes.
- AO instances and immutable uniforms are isolated across pending views/encoders. Submitted slots are reused; replaced dimensions, removed views, profile teardown and device loss retire resources safely. Multiple AO passes multiply visibility before lighting.
- Shared frame packing is extracted from Render3DSystem; orchestration line budgets stay unchanged.

## Acceptance and limits

The [native evidence index](g04-native-compatibility-audit.json) identifies the final exact runtime/harness captures and archived checks. Both native adapters are on the same Mac: AMD RDNA 1 and Intel Gen 9. These are correctness diagnostics, not clean-revision release or performance qualification.

The matrix covers complete material/light lists; all three AO algorithms with isolated direct/emission/ambient/IBL/transmission oracles; shadows, fog, outline and temporal/deformation surfaces; linear HDR, single exposure/output conversion, RTT and reflection children; four-view resize/DPR/near-far/viewport/profile changes; injected replacement, deliberate native device destruction, cancellation and explicit fresh-device initialization; plus unchanged G02/G03 correctness oracles.

CPU/external GPU-stream instances, non-PBR materials, helpers and unsupported mirror main views explicitly fall back to whole-view Forward. They are not claimed as complete hundred-light rendering. The external stream fixture supplies GPU buffers from CPU; the existing GPU-compute instance verifier provides separate coverage. Native `device.destroy()` proves handling of actual `device.lost`, not spontaneous driver recovery or preservation of GPU world state.

AO parity uses Reference/Tiled and analytic contribution tests. Legacy Forward AO darkens composed color and is intentionally not the semantic oracle for selective Deferred AO. The existing three-channel pixel tolerances and all non-AO populations remain unchanged.

## Budgets and release boundary

Current shader cost is 560,954 bytes / 75 WGSL files / 67 variants and pipelines, within the approved 570,000 / 75 / 67 / 67 limits. AO adds 2,992 generated bytes without a new static shader variant. One AO pass adds one RGBA16F visibility target plus an aligned visibility buffer (about 16 bytes/pixel before scratch); two or more AO passes use two ping-pong targets. Existing AO scratch and auxiliary surfaces remain separately accounted. GPU bandwidth and whole-frame performance qualification remain G05.

[Editor installation repair](g04-editor-install-repair.md) is complete. The selected 0.1.x consumption policy remains unchanged; the separate missing published ray-tracing entry is not claimed fixed.

No version changes, commit, push, tag or npm publication are part of this acceptance.

The [G05 handoff](g05-handoff.md) records the remaining performance work and unchanged release boundary.
