## 采样与结果

每项空闲至少 30 秒，预热 120 帧、保留 300 帧。三轮交错适配器与正反顺序；每个设备/场景/算法合并 900 个样本，使用 nearest-rank P95，不删除慢样本。48 次主机前后快照均满足 CPU speed/scheduler=100。CPU runtime 不含 queue wait；GPU span 包含首个 pass 开始到最后一个 pass 结束，cull/resolve/pass sum 另保留。

| 场景 | 设备 | 参考 P95 | Tiled/自动回退 P95 | 门禁结论 |
| --- | --- | ---: | ---: | --- |
| 稀疏 256 灯，cull+resolve | AMD RDNA-1 | 17.184 ms | 3.659 ms | 降低 78.7%，通过 ≥20% 目标 |
| 稀疏 256 灯，cull+resolve | Intel Gen-9 | 130.615 ms | 11.124 ms | 降低 91.5%，通过 ≥20% 目标 |
| 高重叠 128 灯，整段 GPU | AMD RDNA-1 | 13.569 ms | 15.283 ms | 增加 12.6%，未通过 ≤10% 目标 |
| 高重叠 128 灯，整段 GPU | Intel Gen-9 | 69.036 ms | 68.996 ms | 约持平，通过相对目标 |

所有比较的两条路径在 CPU runtime、GPU span、光照阶段和 frame wall 四个通道上，三轮 P95 相对极差均 ≤20%、CV 均 ≤10%。没有引用 G01 两个实例指标的特批例外。

稀疏 256 灯的绝对预算也通过：AMD CPU/GPU/frame wall 为 3.375 / 4.676 / 9.945 ms，Intel 为 4.655 / 13.469 / 24.665 ms。高重叠的 CPU 通过，但 AMD GPU/frame wall 为 15.283 / 20.310 ms、Intel 为 68.996 / 83.830 ms，均超过各自目标。G05 的最终性能资格不能据此宣称完成；高重叠绝对成本仍需优化。

## 同管线 A/B 诊断

三轮独立运行中，高重叠参考与自动回退均实际执行完整灯表 resolve：相同 draws、3 个 render pass、4 次上传与 9,840 B/frame，零 cull pass，预热后零新增 buffer/bind group/render pipeline。源码复核确认两者使用相同参考 Shader 及 pipeline 描述。

另行在同一 device/backend/pipeline 上测量 300 对交错顺序的同帧场景：测试入口只切换是否执行自动选择器。直接参考与自动选择的 GPU P95 为 15.002 / 15.255 ms（约 +1.7%），CPU 为 3.045 / 3.160 ms。逐对 GPU 差值 P95 为 4.857 ms，仍有显著帧级噪声。

该诊断支持继续调查独立初始化/运行环境与资源布局的影响，**不能确证根因，也不替代或豁免上述 12.6% 失败**。原始 A/B 文件、哈希及测试入口见机器复核。没有重置预算、减少灯数或改变 BRDF 计算。

## 图像、索引与资源

128/256 × 稀疏/高重叠 × 两类 GPU 共八个房间组合均通过 HDR/LDR 全图比较，最大通道差均为 0，零 GPU validation error，零清理残留。补充矩阵为短 smoke，只有上述两类具名性能场景使用三轮完整样本。

720p 共 3,600 个 tile，稀疏场景的索引缓冲为 1,900,800 B；含 G-buffer 的计划视图内存为 27,709,728 B，低于 64 MiB。固定第 0 帧的 256 灯列表总引用为 36,681，完整列表为 921,600；128 灯为 18,143 / 460,800，无 tile 溢出。这里是列表引用量，不是实际 fragment 调用次数或显存带宽。逐 tile heatmap 保留在原始文件中。

高重叠从首帧直接走完整灯表时不分配 tile storage，也不运行剔除。强制局部/总容量溢出的正确性仍由独立小场景覆盖，不能用自动回退跳过这些测试。全部完整性能采样预热后新增 buffers/bind groups/render pipelines 均为 0。
