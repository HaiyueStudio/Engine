# G11 状态机帧事务检查点

问题：状态机先提交、文字／布局／绘制后失败时，时钟、触发器、嵌套实例与副作用可能已经推进，重试无法恢复到同一帧。

方法：在原 v2 状态机、混合器和嵌套 owner 内增加 prepare／commit／rollback 屏障。准备阶段保留原快照及事务端口，提交后才推进时钟、确认事件和释放退役实例。准备结果绑定实例与对象身份；期间拒绝重入和输入变更。取消或销毁会撤销暂存状态。原 `update()` 仍在一次调用内完成准备和提交，旧嵌套运行时的可选事务钩子保持兼容；组合准备要求完整钩子。

结论：29 项定向测试通过，包含新增的六项跨帧失败、双实例回滚、输入恢复、身份／重入、嵌套生命周期与回调销毁检查，以及原解析、时间线、混合和状态图检查。三份源码与已批准的隔离候选逐文件 SHA-256 一致，其余 v2 依赖与提交基点一致。

本检查点只提交状态机三文件、回归测试及本记录。HYA Player 的生产装配、字体资源身份与原生绘制、完整公开包及设备验收继续推进；原预算及历史失败保持，不能据此认定 G11 或整版发布完成。
