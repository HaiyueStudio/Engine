# G11 字体与共享视觉基础检查点

问题：同家族字体的资源切换丢失身份，14→18→14 的真实 advance 会变成 18→18→18；全局字体家族名还会让实例互相影响。异步文字位图替换需要保留已提交帧引用的旧像素。

方法：原加载器和 rasterizer 使用资源／家族／样式／字重元组，原生 FontFace 使用实例私有别名，文字文档与样式继承保留资源身份。原动画字形绘制和 OpenType 按需加载保持。位图提供幂等租约，就绪通知覆盖最新代次，旧位图在引用结束后关闭。原运行时增加可选资源端口及共享视觉桥；原描边细分器增加可选覆盖端口并隔离其缓存，默认路径不变。包中包含原有遮罩源标记依赖，不增加 union 实现或依赖包。

结论：直接生产模块的 27 项回归通过，新增九项覆盖真实字体、无平台求值、失败／晚到资源、样式继承和位图生命周期；原字体后到测试按唯一解码对象验证复用，索引别名不重复计为字体。提交基点加本批文件的扩展源码副本完成类型检查与同一组测试，未载入其他未提交的扩展源码。

组合验证已移除 Runtime、Rasterizer、Tessellator 的隔离覆盖，直接读取生产源码：369 项包内回归、26 项原文本回归、双 DPR 各 160 项原生记录及 236 对完整 PNG 回读通过，像素容差仍为 2。21 帧纯求值无 Canvas／FontFace／GPU／网络访问，句柄与资源最终归零。原始身份失败和参考绘制差异保留于本机 G11 证据目录。

这些是基础源码的资格；完整 Player 装配、公开包准入、完整字体／组件／transport 与物理设备验收继续进行。GUI/font 的 55,000 B 上限和已有失败保持，G11 尚未完成。
