# G04 工作缓冲计量结论

问题：1080p／4×MSAA 的整帧 RGBA16F 工作颜色（含 resolve）为 82,944,000 bytes，即 79.10 MiB；旧实现将其计入 64 MiB 像素缓存，导致缓存为零时也无法绘制。

方法：用户于 2026-10-20 明确接受“缓存与工作集分开计量”，记录为 [ADR 0133](../../docs/for-ai/adr/0133-region-cache-working-set-accounting.md)。生产实现使用独立工作缓冲所有者，每次记录完整初始化；替换事务保留旧资源，直到未提交记录和 GPU 队列使用结束。8 区域／64 MiB 继续约束像素缓存，包含缓存 MSAA、resolve、可见裁剪副本及退役重叠。

结论：[生产路径原生报告](../../artifacts/engine-0.2.2/g04/native-working-set-1792504731880.json)通过 6 项检查；4 次完整对照覆盖 33,177,600 个颜色通道，最大差异 0。像素缓存为 0，工作颜色为 82,944,000 bytes，区域深度为 33,177,600 bytes，区域附件合计 116,121,600 bytes。空闲零获取／编码／提交、取消后保留旧输出、重试单次更新、热帧零纹理分配均通过，buffer／texture 清理为零。

区域附件合计不是总 GPU 内存。原生报告另保存完整测试设备资源快照，包含候选、普通全帧参考、输出和 GUI；两组同时存在的纹理估算峰值为 381,936,048 bytes，不能当作单个产品视图或驱动实测驻留。正式总资源与设备性能仍由 G13 验收。

本页只记录工作缓冲计量结论；隔离[原始提案试验](../../artifacts/engine-0.2.2/g04/native-working-prototype-1792503528724.json)及原失败保留，生产夹具已移除测试适配器。后续真实 3D、覆盖层、多视图和设备验证的当前范围统一见 [G04 记录](g04-checks.json)。
