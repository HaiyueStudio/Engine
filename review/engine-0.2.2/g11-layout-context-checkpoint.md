# G11 布局上下文基础

问题：嵌套组件、重复根实例和模型列表共用布局／文本求值器时，需要各自保留数据模型上下文；仅保存 rebind 状态不能让消费者正确更新。

方法：在原 LayoutEvaluator 的组件展开过程中传递按数据命名空间区分的只读作用域。子组件覆盖最近作用域，列表只覆盖所属命名空间；原布局算法、旧双参文本提供器和默认 N-slice 输出保持兼容。生产适配器可保留稳定实例 ID、实际图片源尺寸和镜像方向。

结论：这批通用基础已接入生产源码；仅以 HEAD 加本批四份源码／测试重建，299 个扩展源文件编译通过，52 项定向回归通过。工作树的扩展／全仓类型检查、测试、构建、依赖边界与 API 共八组检查通过。完整组合 Player、组件绑定、仿射输入和公开入口仍待集成，不能据此视为 G11 完成。

完整组合候选另外通过 397 项测试、DPR 1／2 各 191 项原生记录、276 对独立像素重读、21 帧无平台字体求值、原有 26 项文本和 33 项资源生命周期回归。资源恢复回归使用审计设备，不能替代真实设备丢失验收。上述候选仍有 51 份私有源码覆盖，不属于本次提交。
