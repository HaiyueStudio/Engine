# GUI P1：问题、方法与结论

状态：开发与自动化验收完成，2026-11-26。范围：[方案 P1A／P1B](gui-component-visual-plan-20261126.md)，实现归属与 API 审查见 [ADR 0142](../docs/for-ai/adr/0142-gui-p1-composition-and-overlays.md)。供后续 minor 集成；不重新解释已发布的 0.2.4 或原设备资格。

## 问题与方法

P0 有视觉底座，但展示、反馈、菜单与浮层组合不足。新增独立 `gui-display`／`gui-overlays` 入口，以原 GuiElement、GuiModal、布局器、字体、输入域、焦点管理和活动时钟组合；不导入 UI／DOM 组件运行时，不另建渲染器、采样器或每组件帧循环。

交付 Card、Divider、Tag、ImageView、Avatar、Alert、Empty、Spin、Skeleton、ButtonGroup、Segmented，以及 Menu、Dropdown、ContextMenu、Popover、Popconfirm、Dialog、Drawer、NotificationCenter。Expandable 委托已有 Collapse。Tabs／Breadcrumb／Badge／Collapse／Split／虚拟 List、Tree 更新皮肤、变体和 parts；Image／Progress／Slider 扩充展示变体并纳入原序列化、字体覆盖和 damage bounds。

命名部件与借用插槽保留自定义样式。默认皮肤进入原解析器默认层，应用主题资源与实例相同字段仍可覆盖。图片不由组件加载／销毁；借用内容在 dispose 时退还。嵌套菜单只使用一个模态宿主。通知无焦点栈，可见队列有上限；非动效延迟沿用同一可见时钟，隐藏／离屏暂停。

实测修复了几类组合问题：ImageView／Spin 覆盖层改用原绝对定位；滑块 tooltip 消失及自定义阴影的旧／新视觉边界完整保留；Label 使用已解析字号，按字形 advance 换行，避免把图集透明留白误算成换行条件。单值滑块保留旧坐标映射，Progress 的已知文字 getter 继续参与局部绘制，自定义 getter 保留无额外读取的安全回退。菜单危险／禁用色与组内禁用色归成员默认层，应用显式 parts 仍可覆盖。原文字、图像、形状批次与 GPU pass 均复用。

使用与生命周期示例集中在 [指南](../docs/engine-guide/gui-library.md)、[API 索引](../docs/api/gui-library.md)及 [manifest 示例](../examples/gui-library/application.ts)，不复制中间提案。

定向测试涵盖主题／parts 优先级、构造回滚、借用内容、图片监听、通知替换／上限、原动作路径、模态焦点归还、行状态／回收／重入拒绝、序列化、文字自然宽度、原批次及资源退休。原生入口为 `node engine/test/gui-p1-native-gate.mjs`，记录实际服务字节、原生 GPU 错误和静态帧上传；旧 P0 画面与参考保留。

- 全仓类型检查、完整构建及 114 个示例目标通过，2,889 项仓库测试全通过。
- 模块／依赖／责任边界、同步 prepare、索引安全、公开 API、文档、示例目录及 329 项预算策略检查通过。
- [四包报告](../artifacts/gui-p1/public-packages-final-v5/public-packages.json)通过确定性复打包、真实安装、56 个消费者和 8 类运行时检查，包含新增 P1 生命周期消费者。Extensions 实际 packed 为 617,612 B，容量 630,000 B；首次容量失败保留。
